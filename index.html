04 · AI security red teamPersonal project · Oct 2026

Bank Copilot Red Team

A banking AI assistant built to be attacked and then hardened, with attack success measured before and after on the same cases and documented as an OSFI E-23-style model-risk pack. Fictional bank, synthetic data; attacks run only against the local system.

Problem
A system prompt that says “don't leak data” is a suggestion, not a control. The project measures how often prompt-only rules fail under attack, which fixes actually help, and what hardening costs in false refusals.
Built
Two assistants on a local LLM: a customer chat assistant (balances, fee and policy answers, transfers) and an internal email-triage assistant, where indirect prompt injection lives.
Controls
“The model proposes, plain code disposes”: account-ownership checks, a daily-limit policy engine, out-of-band transfer confirmation, an email allow-list and sender-only lookups enforced in code, with PII masking, untrusted-content marking, a prompt canary and answer-grounding layered on top.
Method
A 15-threat model mapped to the OWASP LLM Top 10 (2025). The red-team harness runs dev and held-out attack sets with defences off and on, scores benign tasks for false refusals, reports 95% confidence intervals, and includes an adaptive attacker that rewrites failed attacks.
Findings
Every category backed by a code-level control fell to 0%. Indirect injection is reduced, not solved: one held-out case still lands, with human review of every transfer and triage draft as the backstop. The self-conducted review recommends a limited pilot with conditions, not general release.
Engineering
Hash-chained audit log with SIN redaction; tests pin each baseline hole and the control that closes it; CI runs ruff and pytest on SQLite and PostgreSQL across Python 3.11–3.13.

Hide a message inside an image

Your text is written into the least significant bit of each colour channel. Each pixel value changes by at most 1, which is invisible to the eye. Everything runs in your browser; nothing is uploaded.

Interactive demo of the technique · built for this site

Good to know

  • Hiding is not encrypting. LSB conceals that a message exists; anyone who knows the method can read it. Encrypt first for confidentiality.
  • Capacity is 3 bits per pixel (R, G, B), minus a 4-byte length header.
  • Fragile: lossy compression such as JPEG, resizing or filters destroy the hidden bits. Save as PNG.
